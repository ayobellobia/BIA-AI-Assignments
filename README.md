# BIA-AI-Assignments

Business Intelligence Analysis coursework (Willis College, Diploma 2026) — data cleaning, machine learning and AI projects in Jupyter notebooks (Python).

## Projects

### Project 2 — Data Cleaning and Preparation
`Project 2.ipynb`

Cleaned and prepared historical stock market data: merged 10,597 historical prices with 6,460 stock listings on ticker, handled missing values, removed outliers with the IQR method (37 close-price outliers, 1,577 volume outliers), fixed invalid values, and engineered features — 7-day and 30-day moving averages, daily returns, and a 7-day future close price for ML prediction.

Tools: pandas, NumPy, matplotlib, seaborn.

### Project 4 — Unsupervised Learning (digit clustering)
`Project4.ipynb`

Explored the MNIST handwritten digits dataset (1,797 samples): normalized pixel values, visualized samples, and grouped digits with KMeans clustering, PCA and t-SNE.

Tools: scikit-learn, NumPy, matplotlib.

### Assignment 13 — LSTM text generation
`Assignment13.ipynb`

A lightweight implementation of a GPT-like text generation model using LSTM networks. Demonstrates the core concepts of generative AI with minimal dependencies and fast training times.
